# Degentellegence brand kit

Start with `Degentellegence-Brand-Guidelines.pdf`. The editable companion is `Brand-Guidelines.md`.

- `assets/degentellegence-symbol-red.png`: red magnifier/network symbol, transparent PNG, 1254 x 1254.
- `assets/degentellegence-avatar-red.png`: white symbol on red, opaque PNG, 1254 x 1254.
- `assets/degentellegence-lockup-preview.png`: typeset horizontal signature on white, 2200 x 480.
- `brand-tokens.css`: reusable palette, typography, spacing and sample component styles.
- `fonts/`: Manrope variable and IBM Plex Mono regular/medium, plus license notices.
- `creation-notes.md`: artwork prompts and generation provenance.

Spelling is intentional: **Degentellegence**. Logo images are raster assets, not editable vector outlines. The guide's product examples are synthetic visual applications; no application changes were made.
